SQL 코딩테스트 대비 프로그래머스 공부

업그레이드 된 아이템 구하기

문제 

![](__MEDIA__/52928e137b305f01d058581c0364f20e021c489805702f2727d8f517a0abd189.png)

프로그래머스 코딩테스트

고려 할 부분 

*   ITEM\_TREE 테이블에 조회 가능한 컬럼이 존재하지 않음.
*   하지만, 희귀도가 RARE 인 아이템을 ITEM\_ID 값으로 조회해서 ITEM\_TREE 의 PARENT\_ITEM\_ID 값과 비교해야함

미흡했던 부분

*   서브쿼리에 대한 동작 방식
*   IN 연산자를 사용하여 포함된 여부를 체크 했어야 하는데 ' = ' 조건으로만 조회를 하려고 하였음. 실제 그 값이 포함되어 있는지 여러개의 뿌리 아이템이 존재함을 고려했어야 하는데 그렇지 못함.

제출한 정답.

```
-- 코드를 작성해주세요
SELECT a.ITEM_ID,a.ITEM_NAME,a.RARITY 
FROM ITEM_INFO a
INNER JOIN ITEM_TREE b
ON a.ITEM_ID = b.ITEM_ID
WHERE b.PARENT_ITEM_ID IN (SELECT ITEM_ID FROM ITEM_INFO WHERE RARITY = 'RARE')
ORDER BY a.ITEM_ID DESC
```

진료과별 총 예약 횟수 출력하기 

![](__MEDIA__/ff69b4b120cb1bf2c02df07000596d3cc2ab7772343246aefb197012d995ce86.png)

프로그래머스 코딩테스트

고려한 부분 

*   진료과코드 별로 조회하는 SQL문이기에, 진료과코드를 GROUP BY 하여 그룹화
*   진료과별 예약한 환자수를 기준으로 오름차순이기에, 그룹화 된 진료과별 예약 건수를 Count 하여 Order by 수

제출한 정답.

```
SELECT A.MCDP_CD AS '진료과코드', COUNT(A.APNT_YMD) AS '5월예약건수'
FROM APPOINTMENT A
WHERE DATE_FORMAT(A.APNT_YMD, '%Y-%m') = '2022-05'
GROUP BY A.MCDP_CD
ORDER BY COUNT(A.APNT_YMD) ASC, A.MCDP_CD ASC
```

성분으로 구분한 아이스크림 총 주문량

![](__MEDIA__/45155b197d6d01e422271b8e0a5f406046c0f9f6b88dbe165c5d2824b132f955.png)

프로그래머스 코딩테스트

고려한 부분

*   ICECREAM\_INFO 테이블에는 TOTAL\_ORDER 가 있지 않다. 고로 공통 컬럼인 FLAVOR 을 활용해 JOIN 하여 TOTAL\_ORDER 값을 도출하려고 하였다.
*   INNER JOIN 이후 성분 타입별로 총 주문량을 출력해야 하기에, INGREDIENT\_TYPE 별로 GROUP BY 하여 합계가 출력이 가능하도록 하였다.

제출한 정답. 

```
SELECT A.INGREDIENT_TYPE, SUM(B.TOTAL_ORDER) AS TOTAL_ORDER
FROM ICECREAM_INFO A
INNER JOIN FIRST_HALF B ON A.FLAVOR = B.FLAVOR
GROUP BY A.INGREDIENT_TYPE
ORDER BY B.TOTAL_ORDER ASC
```
