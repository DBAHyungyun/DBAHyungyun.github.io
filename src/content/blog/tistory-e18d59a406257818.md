오늘은 DB 구성이나 설치 대신 Lv1, Lv2 쉬운 SQL 문 작성을 해보았다. 

링크 : [https://school.programmers.co.kr/learn/challenges?tab=sql\_practice\_kit](https://school.programmers.co.kr/learn/challenges?tab=sql_practice_kit)

1\. 평균 일일 대여 요금 구하기

문제 : CAR\_RENTAL\_COMPANY\_CAR 테이블에서 자동차 종류가 'SUV'인 자동차들의 평균 일일 대여 요금을 출력하는 SQL문을 작성해주세요. 이때 평균 일일 대여 요금은 소수 첫 번째 자리에서 반올림하고, 컬럼명은 AVERAGE\_FEE 로 지정해주세요.

제출한 답 : select round(AVG(DAILY\_FEE)) AS average\_fee   
from CAR\_RENTAL\_COMPANY\_CAR   
where CAR\_TYPE = 'SUV'

2\. 조건에 부합하는 중고거래 댓글 조회하기

문제 : USED\_GOODS\_BOARD와 USED\_GOODS\_REPLY 테이블에서 2022년 10월에 작성된 게시글 제목, 게시글 ID, 댓글 ID, 댓글 작성자 ID, 댓글 내용, 댓글 작성일을 조회하는 SQL문을 작성해주세요. 결과는 댓글 작성일을 기준으로 오름차순 정렬해주시고, 댓글 작성일이 같다면 게시글 제목을 기준으로 오름차순 정렬해주세요.

제출한 답 : select a.TITLE,a.BOARD\_ID,b.REPLY\_ID,b.WRITER\_ID,  
b.CONTENTS,TO\_CHAR(b.CREATED\_DATE,'YYYY-MM-DD') AS CREATE\_DATE  
from USED\_GOODS\_BOARD a  
inner join USED\_GOODS\_REPLY b  
ON a.BOARD\_ID = b.BOARD\_ID  
where TO\_CHAR(a.CREATED\_DATE,'YYYYMM') = '202210'  
order by b.CREATED\_DATE, a.TITLE

3\. 재구매가 일어난 상품과 회원 리스트 구하기

문제 : ONLINE\_SALE 테이블에서 동일한 회원이 동일한 상품을 재구매한 데이터를 구하여, 재구매한 회원 ID와 재구매한 상품 ID를 출력하는 SQL문을 작성해주세요. 결과는 회원 ID를 기준으로 오름차순 정렬해주시고 회원 ID가 같다면 상품 ID를 기준으로 내림차순 정렬해주세요.

제출한 답 : select a.user\_id,a.PRODUCT\_ID from ONLINE\_SALE a   
group by a.product\_id,a.user\_id  
HAVING count(\*) > 1  
order by a.user\_id asc , a.PRODUCT\_ID desc

(재구매를 기준으로 쿼리를 작성해야 했기 때문에, 중복데이터를 찾을때 주로 사용하는 Having 절을 사용하여 작성하였다.)
