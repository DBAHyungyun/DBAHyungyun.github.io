오늘은 오라클의 기본 아키텍쳐에 대해 간단하게 공부해보려고 합니다. 오라클 아키텍쳐란 양이 정말 방대하고 어려워서 시간나고 공부 할 때 마다 여러번에 걸쳐서 업로드 하려고 합니다. 

오늘은 오라클 데이터베이스의 전제척인 흐름도와 그 구성에 대한 기초적인 부분을 알아보려고 한다.

* * *

보편적으로 인터넷에 검색하면 나오는 오라클의 흐름도이다. 이것을 간단히 살펴보면 Oracle 데이터베이스 인스턴스가 사용하는 공유 메모리 영역인 SGA, SGA 메모라와 백그라운드 프로세스로 구성된 집합체인 인스턴스 (Instance), 데이터 파일들의 집합인 데이터베이스 (Database) 이렇게 크게 3가지로 정의 할 수 있다.

오라클 아키텍쳐 크게 3가지 부분

이제 SGA와 백그라운드 프로세스, 데이터파일 영역에 대해 더 자세히 보자면,

SGA : Oracle 데이터베이스 인스턴스가 사용하는 공유 메모리 영역으로, 여러 프로세스들이 데이터를 공유해서 사용 할 수 있는 메모리 영역 

Shared Pool (공유 풀) 영역

\- Library Cache : 실행 된 SQL이나 PL/SQL을 저장하여 반복 실행 시 성능을 향상 시켜주는 역할을 한다. (라이브러리 캐시의 내용을 깊게 설명하려면, 하드파싱과 소프트파싱도 함께 설명해야하는데, 이 부분은 다음에 성능과 아키텍쳐를 공부하면서 자세히 공부해보도록 하겠다.)

\- Data Dictionary Cache : 테이블, 인덱스 등의 최근 사용된 오브젝트들의 정보가 저장되는 메모리 영역

Database Buffer Cache (데이터 버퍼 캐시)

\- 디스크에서 읽어온 데이터를 저장하는 캐시

\- 사용자가 자주 접근하고 사용하는 데이터를 빠르게 제공해서 성능을 향상하는 역할을 한다.

Log Buffer (로그 버퍼)

\- 변경된 데이터 (트랜잭션이 발생한 경우)를 기록하는 메모리 영역, Redo Log files 로 기록이 된다.

\- DB에 장애가 발생 할 시에 복구 될 수 있도록 보장을 해준다.

* * *

SGA + 백그라운드 프로세스 영역 : 인스턴스라고도 불리며, SGA (메모리) 영역과 백그라운드 프로세스로 구성된 집합체이다.

흐름도에 나와있는 백그라운드 프로세스를 참고하여 몇가지 간단하게 정의하자면,

필수 백그라운드 프로세스 

\- SMON(System Monitor) : 시스템 모니터, 오라클 인스턴스를 관리하는 프로세스  
\- PMON(Process Monitor) : 오라클 서버에서 사용되는 각 프로세스를 감시하는 프로세스  
\- DBWn(Database Writer) : DB Buffer Cache 의 Dirty Buffer 의 내용을 Data File 에 저장하는 역할 수행 (CKPT가 일어났을 때, Time Out 이 발생 했을 때, Dirty Buffer 가 임계치 값을 지났을 때 등)  
\- LGWR(Log Writer Redo) : Buffer Cache에서 발생한 모든 변화 (트랜잭션) 를 기록하는 프로세스  
\-  CKPT(Checkpoint) : 모든 변경된 데이터베이스 버퍼를 디스크 내의 데이터 파일로 저장하는 프로세스   
\- MMON / MMNL (Manageability Monitor) : AWR에 SGA 의 일부 영역 SIZE 조절 / 활성 세션 이력 정보 수집 및 변화율 계산  
\- RECO (Recoverer) : 복구 프로세스

필수가 아닌 백그라운드 프로세스   
\- ARCn (Archiver) : 아카이버, Online RedoLog File이 꽉차거나 DBA가 ALTER SYSTEM SWITCH LOGFILE의 명령어로 강제적으로 LOG SWITCH가 발생할 때 리두 로그 파일들을 지정된 저장장치로 저장하는 역할

* * *

마지막으로 데이터베이스는 데이터 파일의 집합으로 실제 데이터가 저장된 파일들의 집합을 의미한다.

데이터 베이스의 주요 파일로는

\- Datafile : 테이블, 인덱스 등의 데이터를 저장하는 파일

\- Control File : 데이터베이스의 구조와 상태 정보를 포함하는 파일

\- Redo Log Files : 데이터베이스의 변경된 데이터를 복구 할 수 있도록 기록해두는 곳. (위의 SGA 영역 Log Buffer 와 연관이 있다.)

\- Archived Log Files : Redo Log Files 의 백업본으로 장애 발생 시 복구에 사용

한마디로 요약하자면,

SGA (System Global Area) : 공유 메모리 영역

Instance (SGA + 백그라운드 프로세스) : 데이터베이스를 관리하고 운영하는 실행 환경

Database (데이터 파일의 집합) : 실제 데이터가 저장되는 파일

이렇게 정리할 수 있으며, 전체적인 오라클 아키텍쳐를 이해하는데 굉장히 중요한 부분으로 개념을 잘 알아두면 좋을 것 같다.

오늘은 이렇게 간단하게만 오라클 아키텍쳐 전반적인 흐름도를 공부해보았다. 다음에는 더 심화된 내용을 공부해보도록 하겠다.
