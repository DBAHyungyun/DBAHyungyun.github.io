안녕하세요. 오늘은 AWS의 EC2 환경에서 Docker를 구성한 뒤 Kubernetes를 활용한 PostgreSQL을 구성해보려고 합니다.

우선 AWS 환경에서 EC2와 Docker를 구성하기 위해서는 EC2, Docker,k8s가 어떤건지 개념을 먼저 확인해야 할 것 같은데요.

간략하게 개념에 대해서 확인해보겠습니다.

### EC2 / Docker / K8s 란 ?

AWS EC2 란?

\- Elastic Compute Cloud로 Amazon Web Service 에서 제공하는 컴퓨트 자산이다.  
\- EC2에 SSH로 접근하게 되면, On-prem 환경의 리눅스 컴퓨터 1대에 접속하는 것과 같다 

Docker란 ?

\- Docker는 OS 커널을 호스트와 공유하면서 프로세스 단위로 격리하는 컨테이너 기술이다.  
\- VM처럼 게스트 OS 전체를 부팅하지 않기 때문에 훨씬 가볍고 시작 속도가 빠르다.

K8s란 ?

\- Kubernetes 의 약자로 K와 s 사이에 8개의 알파벳이 있어 k8s 라고도 불리운다.

\- 컨테이너를 대규모로 배포하고 관리하는 시스템이다.

\- k8s는 Pod가 비정상 상태(liveness probe 실패)가 되면 자동으로 재시작해준다. 다만 이건 프로세스 재시작 수준의 자동화이고, DB의 데이터 정합성이나 복제 상태까지 이해하고 장애조치를 해주는 건 아니다.

\- 여러개의 docker를 관리해주는 매니저의 개념이다.

### 실습 환경 구성

docker도 생성한 뒤, k8s에서 PostgreSQL을 관리 구성하기 위해서는 t3.medium을 최소 사양으로 지정해주어야 할 것 이라고 생각하여 EC2는 t3.medium으로 구성하였습니다. 

![](__MEDIA__/fc40f2518200ecc794d6af0fae2bdfc014399253a770b392b23915dc527e79ea.png)

구성된 EC2 환경에서 아래 명령어를 참고하여 docker를 설치하여 확인해보게 된다면 아래와 같습니다.

### Docker에 PostgreSQL Pull 하기

이렇게 설치된 Docker에 PostgreSQL 이미지를 Pull 해주어 엔진을 구성해줍니다.

아래와 같은 명령어로 이미지를 불러오게 된다면, 정상적으로 PostgreSQL 17 버전의 이미지를 Pull 하는 것을 볼 수 있습니다.

```
docker run --name pg-test \
  -e POSTGRES_PASSWORD=test1234 \
  -e POSTGRES_DB=testdb \
  -p 5432:5432 \
  -v pgdata:/var/lib/postgresql/data \
  -d postgres:17
```

```
docker run --name pg-test2 \
  -e POSTGRES_PASSWORD=test1234 \
  -e POSTGRES_DB=testdb \
  -e POSTGRES_USER=postgres \
  -e TZ=Asia/Seoul \
  -e POSTGRES_INITDB_ARGS="--data-checksums" \
  -p 5433:5432 \
  -v pgdata2:/var/lib/postgresql/data \
  --restart unless-stopped \
  --memory="1g" \
  --cpus="1.0" \
  --shm-size=256mb \
  --health-cmd="pg_isready -U postgres" \
  --health-interval=10s \
  --health-timeout=5s \
  --health-retries=3 \
  -d postgres:17 \
  -c shared_buffers=256MB \
  -c max_connections=100 \
  -c log_min_duration_statement=200
```

### 정리

최종적으로 저희가 현재 구성한 환경을 확인해보면 아래와 같게 그릴 수 있습니다.

```
                                      AWS
                                       │
                                       ▼
                                      EC2
                                (컴퓨터 한 대)
                                       │
                                    Docker
                                (컨테이너 실행기)
                                       │
                                       ▼
                               PostgreSQL Container
                                       │
                                       ▼
                                PostgreSQL Database
```

이렇게 Docker 환경에서 PostgreSQL 이미지를 불러와 DB 환경을 구성해봤는데요. 생각보다 작성할 내용이 많아서 다음번에는 k8s를 활용하여 docker를 관리하고 시스템을 관리할 수 있게끔 실습해보도록 하겠습니다.
