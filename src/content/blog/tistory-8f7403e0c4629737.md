대여 횟수가 많은 자동차들의 월별 대여 횟수 구하기

![](__MEDIA__/4a2b7ca2ab1fe32d784af2d7f8aad14b0ab0c3c770bde5b02dc4161c83ad6c5e.png)

프로그래머스 코딩테스트

고려할 점

*   총 대여 횟수가 5인 자동차에 대하여 월별로 확인해야 하므로 총 대여횟수가 5인 CAR\_ID 를 조회
*   2번의 GROUP BY 를 사용하여 CAR\_ID 의 전체 집계가 5 이상인것, 그 뒤로 월별로 출력할 것 고려

간과한 점 

*   GROUP BY 에 MONTH 와 CAR\_ID 2가지로 그룹화하여 정답을 출력하여야 했으나 그렇지 못함
*   HAVING 절에서 아직 미흡한 모습

```
SELECT MONTH(START_DATE) AS MONTH ,CAR_ID,COUNT(*) AS RECORDS
FROM CAR_RENTAL_COMPANY_RENTAL_HISTORY  
WHERE CAR_ID IN (SELECT CAR_ID
               FROM CAR_RENTAL_COMPANY_RENTAL_HISTORY
               WHERE MONTH(START_DATE) BETWEEN '08' AND '10'
               GROUP BY CAR_ID
               HAVING COUNT (*) >= 5) 
AND MONTH(START_DATE) BETWEEN '08' AND '10'
GROUP BY MONTH,CAR_ID
ORDER BY MONTH ASC, CAR_ID DESC  
               
/* 총 대여 회수가 5개인 자동차에 대해서 해당 기간 동안 (08월 ~ 10월) 월별 자동차 ID 별 총 대여 횟수) */
```

Front End 개발자 찾기

![](__MEDIA__/c6441af83f43cd37144f64f2ae5b252f8e24eae4cf81085e7f8ff5e0d69b679c.png)

프로그래머스 문제

고려할 점

*   비트 연산자가 출력되는 부분에서 비교할 컬럼을 선정 SKILL\_CODE 컬럼과 CODE 컬럼을 ㅗ비트 연산 비교
*   비트 연산을 비교하여 출력한 뒤 Category 가 Front End 인 부분 필터링

놓쳤던 점

*   비트연산자 INNER JOIN 을 사용하지 않고 계속 컬럼간의 JOIN 을 하려해서 문제가 풀리지 않음

오답 쿼리

*   비트마스크 연산으로 1:1 일치가 구조적으로 불가능하지만, 1:1 일치를 사용
*   완전 일치함을 요구, 문제에서는 Front End 스킬 하나라도 가진 사람을 필터링 해야하므로 조건이 맞지 않음
*   JOIN 결과로 인해 중복된 개발자 레코드가 생길 수 있는데, 이부분을 간과함 DISTINCT 옵션을 활용하여 혹여나 중복된 개발자 코드가 있을지 중복 제거해줌 

```
SELECT A.ID,A.EMAIL,A.FIRST_NAME,A.LAST_NAME 
FROM DEVELOPERS A
INNER JOIN SKILLCODES B
  ON A.SKILL_CODE = B.CODE
WHERE A.SKILL_CODE & (SELECT SUM(CODE)
                      FROM SKILLCODES
                      WHERE CATEGORY = 'Front End') = A.SKILL_CODE
ORDER BY A.ID
```

제출한 정답

```
-- 코드를 작성해주세요
SELECT DISTINCT A.ID,A.EMAIL,A.FIRST_NAME,A.LAST_NAME 
FROM DEVELOPERS A
INNER JOIN SKILLCODES B
ON A.SKILL_CODE & B.CODE > 0
WHERE B.CATEGORY = 'Front End'
ORDER BY A.ID ASC
```

우유와 요거트가 담긴 장바구니 (Summer/Winter Coding 2019)

![](__MEDIA__/818c940c8f896efe439449a806e72aa2a470446cc9c009b15f7b9e7889e70677.png)

프로그래머스 코딩테스트

접근방법

*   전체 테이블을 조회했을 당시에, 같은 ID로 지정되어 있는 값이 많은것으로 미루어보아 GROUP BY 사용 할것으로 예상
*   동시에 Milk 와 Yogurt를 구매한 이력을 확인하기 위해서는 2번의 값 비교가 필요하다고 판단.

제출한 정답

```
-- 코드를 입력하세요
SELECT CART_ID FROM CART_PRODUCTS
WHERE CART_ID IN (SELECT CART_ID
                FROM CART_PRODUCTS
                WHERE NAME = 'Milk')
AND CART_ID IN (SELECT CART_ID
                FROM CART_PRODUCTS
                WHERE NAME = 'Yogurt')
GROUP BY CART_ID
ORDER BY CART_ID
```

서브쿼리가 두번 반복되는 비효율성이 존재 할 것이라고 생각해서 여러 블로그를 참고하여 다시 생각해본 코드

*   DISTINCT 를 활용하여 동일 상품이 여러번 담겨 있어도 2까지만 카운팅 하도록 세팅
*   Milk, Yogurt 모두 한번의 스캔으로 모아서 집계한 뒤, 두 종류가 모두 있는 CART\_ID 로 필터링 

```
SELECT CART_ID
FROM   CART_PRODUCTS
WHERE  NAME IN ('Milk', 'Yogurt')
GROUP  BY CART_ID
HAVING COUNT(DISTINCT NAME) = 2
ORDER  BY CART_ID;
```
